# 🎟️ Jigs Events

An AI-powered full-stack Event Management & Ticket Registration Platform built with React, TypeScript, Django REST Framework, Razorpay, QR Authentication, and an Android QR Scanner App.

🌐 Live Website: https://jigs-event.vercel.app/

---

# 🚀 Overview

Jigs Events is a modern event management ecosystem that allows organizers to create and manage events while users can browse, register, purchase tickets, and receive QR-based digital passes.

The platform also includes a dedicated Android Scanner App for real-time ticket verification during event entry.

# 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript + Vite |
| Styling | Tailwind CSS + Framer Motion |
| Backend | Django + Django REST Framework |
| Authentication | JWT (SimpleJWT) |
| Database | PostgreSQL / SQLite |
| Payments | Razorpay |
| AI | Hugging Face API |
| QR Generation | qrcode |
| PDF Tickets | ReportLab |
| Mobile App | React Native + Expo |
| Deployment | Vercel + Render |
